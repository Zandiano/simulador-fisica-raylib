# simulador-fisica-raylib
## Pequeno "simulador" de fisica com partículas usando a biblioteca raylib em C

Controls:

R = Reset
Space = Pause
PageUp = +Pull
PageDown = -Pull
Arrow Up = +Randomness
Arrow Down = -Randomness
Arrow Right = +Gravity
Arrow Left = -Gravity
Z = Center of Mass
P = Gravity On/Off
